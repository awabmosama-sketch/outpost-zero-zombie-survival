## 🎮 Overview

**Outpost Zero: Zombie Survival** is an action-packed, self-contained tactical round-based shooter built on HTML5 Canvas. Step into quarantined deployment theaters, fend off realistic mutant strains, upgrade your armory through 4 MK Tiers, and infuse your weapons with lethal power-ups using the round-activated **Cyber-Forge** overclocking machine[cite: 2].

---

## ✨ Key Features

* **Cross-Platform Play (Desktop & Mobile):** Fully playable on desktop browsers (Keyboard/Mouse) and mobile/tablet touch devices with responsive virtual thumbsticks and on-screen action buttons[cite: 2].
* **5 Distinct Deployment Theaters:** Choose from *Outpost Zero* (Military Bunker), *Cryo Tundra* (Ice Shelf), *Toxic Jungle* (Bio-Dome), *Scorched Dunes* (Desert Canyon), and *Neon Metropolis* (Quarantined Cyber-City), each featuring unique hazard weather and regional mutant strains[cite: 2].
* **4 Advanced Arsenal Tiers & Overclocks:** Arm yourself with the *M249 Titan* (LMG), *Vector-9* (SMG), *Bore-12 Striker* (Shotgun), and *Twin Apex .45s* (Pistols). Upgrade through MK-I to MK-IV or infuse with Plasma, Tesla Lightning, Cryo Permafrost, or Micro-Missile Warheads[cite: 2].
* **Round-Activated Cyber-Forge:** Starting in Round 3, interact with the central arena Cyber-Forge machine to supercharge your weapons[cite: 2].
* **Live Session Telemetry Dashboard:** Real-time tracking of scores, mutant neutralization breakdowns, accuracy percentages, and session duration (stored persistently until browser tab closure)[cite: 2].
* **Tactical Gear & Armory Shop:** Deploy M67 Frag Grenades, M18A1 Claymore Proximity Mines, Combat Medkits, Kevlar Armor, and Adrenaline Combat Stims[cite: 2].
* **Synthesized Web Audio API:** Full custom procedural sound effects for gunfire, reloads, explosions, and UI interactions without external audio dependencies[cite: 2].

## 🕹️ Controls & Keybindings

### **Desktop (Keyboard & Mouse)**
| Key / Control | Action |
| :--- | :--- |
| **`W`, `A`, `S`, `D` / Arrows** | Move Operative & Tactical Stride[cite: 2] |
| **`Mouse Cursor`** | Aim Direction & Laser Sight Alignment[cite: 2] |
| **`Left Click`** | Fire Primary Caliber Weapon[cite: 2] |
| **`R`** | Reload Active Magazine[cite: 2] |
| **`1` – `4`** | Switch Weapon Slots[cite: 2] |
| **`Q` / `E` / `Wheel`** | Cycle Active Weapons[cite: 2] |
| **`B`** | Open Armory Shop Depot[cite: 2] |
| **`U`** | Upgrade Active Weapon (MK Tiers)[cite: 2] |
| **`F`** | Interact with Cyber-Forge Machine (Round 3+)[cite: 2] |
| **`G`** | Throw M67 Frag Grenade[cite: 2] |
| **`X`** | Plant M18A1 Claymore Mine[cite: 2] |
| **`TAB`** | Open Live Session Telemetry Dashboard[cite: 2] |
| **`P` / `ESC`** | Pause Combat Mission[cite: 2] |

### **Mobile & Tablets (Touch Controls)**
* **Left Thumb:** Drag anywhere on the left side of the screen on the virtual thumbstick to move[cite: 2].
* **Right Thumb:** Drag on the right side of the screen to aim and fire[cite: 2].
* **On-Screen Buttons:** Dedicated touch-friendly buttons for Reload, Grenade, Mine, Cyber-Forge interaction, Armory Shop, and Stats Dashboard[cite: 2].
* **Orientation Notice:** Automatically prompts to rotate your device if held in portrait mode[cite: 2].

## 🚀 Getting Started Locally

### Prerequisites
Make sure you have **Node.js** installed on your system.

### Installation & Execution

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/awabmosama-sketch/outpost-zero-zombie-survival.git](https://github.com/awabmosama-sketch/outpost-zero-zombie-survival.git)
   cd outpost-zero-zombie-survival

```

2. **Install dependencies:**
```bash
npm install

```


3. **Run the development server:**
```bash
npm run dev

```


4. Open your browser and navigate to the local development URL provided by Vite (typically `http://localhost:3000` or `http://localhost:5173`).
