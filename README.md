## 🎮 Overview

**Outpost Zero: Zombie Survival** is an action-packed, self-contained tactical round-based shooter built on HTML5 Canvas. Step into quarantined deployment theaters, fend off realistic mutant strains, upgrade your armory through 4 MK Tiers, and infuse your weapons with lethal power-ups using the round-activated **Cyber-Forge** overclocking machine.

---

## ✨ Key Features

* **5 Distinct Deployment Theaters:** Choose from *Outpost Zero* (Military Bunker), *Cryo Tundra* (Ice Shelf), *Toxic Jungle* (Bio-Dome), *Scorched Dunes* (Desert Canyon), and *Neon Metropolis* (Quarantined Cyber-City), each featuring unique hazard weather and regional mutant strains.
* **4 Advanced Arsenal Tiers & Overclocks:** Arm yourself with the *M249 Titan* (LMG), *Vector-9* (SMG), *Bore-12 Striker* (Shotgun), and *Twin Apex .45s* (Pistols). Upgrade through MK-I to MK-IV or infuse with Plasma, Tesla Lightning, Cryo Permafrost, or Micro-Missile Warheads.
* **Round-Activated Cyber-Forge:** Starting in Round 3, interact with the central arena Cyber-Forge machine to supercharge your weapons.
* **Live Session Telemetry Dashboard:** Real-time tracking of scores, mutant neutralization breakdowns, accuracy percentages, and session duration (stored persistently until browser tab closure).
* **Tactical Gear & Armory Shop:** Deploy M67 Frag Grenades, M18A1 Claymore Proximity Mines, Combat Medkits, Kevlar Armor, and Adrenaline Combat Stims.
* **Synthesized Web Audio API:** Full custom procedural sound effects for gunfire, reloads, explosions, and UI interactions without external audio dependencies.

## 🕹️ Controls & Keybindings

| Key / Control | Action |
| :--- | :--- |
| **`W`, `A`, `S`, `D` / Arrows** | Move Operative & Tactical Stride |
| **`Mouse Cursor`** | Aim Direction & Laser Sight Alignment |
| **`Left Click`** | Fire Primary Caliber Weapon |
| **`R`** | Reload Active Magazine |
| **`1` – `4`** | Switch Weapon Slots |
| **`Q` / `E` / `Wheel`** | Cycle Active Weapons |
| **`B`** | Open Armory Shop Depot |
| **`U`** | Upgrade Active Weapon (MK Tiers) |
| **`F`** | Interact with Cyber-Forge Machine (Round 3+) |
| **`G`** | Throw M67 Frag Grenade |
| **`X`** | Plant M18A1 Claymore Mine |
| **`TAB`** | Open Live Session Telemetry Dashboard |
| **`P` / `ESC`** | Pause Combat Mission |
