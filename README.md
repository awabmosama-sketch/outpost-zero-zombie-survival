## 🎮 Overview

**Outpost Zero: Zombie Survival** is an action-packed, self-contained tactical shooter built on HTML5 Canvas and React. Step into quarantined tactical zones, fend off relentless mutant hordes, upgrade your arsenal through MK tiers, and unlock power-ups via the round-activated **Cyber-Forge** machine.

---

## ✨ Key Features

* **5 Distinct Deployment Theaters:** Choose from *Outpost Zero* (Bunker), *Cryo Tundra* (Ice), *Toxic Jungle* (Bio-Dome), *Scorched Dunes* (Desert), and *Neon Metropolis* (Cyber-City), each featuring unique hazard weather and regional mutant strains.
* **Advanced Arsenal & Tiers:** Arm yourself with LMGs, SMGs, Shotguns, and Twin Apex Pistols. Upgrade weapons across 4 MK Tiers.
* **Round-Activated Cyber-Forge:** Infuse your weapon with Plasma Overcharges, Tesla Lightning Arcs, Cryo Permafrost, or Micro-Missile Warheads starting in Round 3.
* **Live Session Telemetry Dashboard:** Real-time tracking of scores, mutant neutralization breakdowns, accuracy metrics, and session duration.
* **Tactical Gear & Consumables:** Deploy M67 Frag Grenades, M18A1 Claymore Proximity Mines, and visit the in-game Armory Shop.
* **Synthesized Web Audio API:** Full custom procedural sound effects for gunfire, reloading, explosions, and UI interactions without external audio dependencies.

## 🕹️ Controls & Keybindings

| Key / Control | Action |
| :--- | :--- |
| **`W`, `A`, `S`, `D` / Arrows** | Move Operative & Tactical Stride |
| **`Mouse Cursor`** | Aim Direction & Laser Sight Alignment |
| **`Left Click`** | Fire Primary Caliber Weapon |
| **`R`** | Reload Active Magazine |
| **`1` – `4`** | Switch Weapon Slots |
| **`Q` / `E` / `Wheel`** | Cycle Active Weapons |
| **`B`** | Open Armory Shop Depot |
| **`TAB`** | Open Live Session Telemetry Dashboard |
| **`F`** | Interact with Cyber-Forge Machine (Round 3+) |
| **`G`** | Throw M67 Frag Grenade |
| **`X`** | Plant M18A1 Claymore Mine |
| **`P` / `ESC`** | Pause Combat Mission |
